# Hi, I'm Megildur 👋

I make Discord bots and the websites and games that go with them, mostly in Python with discord.py.

## What I'm working on

| Project | What it is |
| --- | --- |
| [**Botzilla**](https://bot-zilla.app) | An all-in-one Discord bot: moderation, AutoMod, tickets, giveaways, leveling, a cross-server economy and marketplace, pixel-art pets, games, voice rooms and server tools, with a web dashboard. |
| [**WordCounter**](https://github.com/Megildur/WordCounter) | Counts words, messages, attachments, emojis, keywords and swears per member and channel, with monthly history, chat backfills and a dashboard at [wordcounter.dev](https://wordcounter.dev). |
| [**Botzilla: Specimen 01**](https://bot-zilla.app/specimen-01/) | A pixel-art adventure game starring Botzilla, playable in the browser, as a Discord Activity and on Android. |
| [**Sentiment**](https://github.com/Megildur/sentiment_bot) | A Discord bot for playing the Sentiment tabletop game. |
| [**Whiskers**](https://github.com/Megildur/whiskers) | A cat that lives in your Discord server, runs on a local AI model and grows into whoever its server teaches it to be. |

## Tools I use

Python · discord.py · aiohttp · MySQL / MariaDB · SQLite · JavaScript · Phaser · Pillow
